# 学生劳务费发放助手

本机小工具：**维护长期人员库 → 勾选本次发放对象 → 按科研/非科研模板导出 Word、PDF 明细表和 Excel 名单**。

Windows / macOS / Linux 都能用，只用 Python，不需要 Node、不需要编译。

## 启动

| 平台 | 怎么做 |
| --- | --- |
| Windows | 双击 **`run.cmd`** |
| macOS / Linux | `chmod +x run.sh && ./run.sh` |
| 任意平台 | `python3 run.py` |

浏览器会自动打开 <http://127.0.0.1:8765>。**用完关掉那个终端窗口就停止服务。**

```bash
python3 run.py --port 9000   # 指定端口（默认 8765，被占用会自动往后找）
python3 run.py --no-open     # 不自动开浏览器
```

首次打开会看到两个示例学生（来自你的模板文件），可以直接改成你自己的名单。

## 长期人员库与分组

人员**录一次就长期保存**，关掉浏览器、重启服务、换月份、清空本次名单都不会丢。
只有你明确点「删除人员」才会移出人员库。

### 分组分两种，规则不一样

| | 身份组 | 项目组 |
| --- | --- | --- |
| 例子 | 研究生 / 本科生 / AI 补充 | 国家重点研发 / 横向课题 A |
| 一个人能有几个 | **只能有一个** | 可以同时属于多个 |
| 用来干什么 | **导入名单**和**按组勾选发放**都按它 | 筛选、批量勾选，方便按项目找人 |
| 为什么要互斥 | 同一个人不会既算研究生又算本科生，**从根上避免重复发放** | 一个人确实会同时参与多个项目 |

> 所以「研究生」和「本科生」绝不会重叠；而「国家重点研发」里可以既有研究生也有本科生。

### 常用操作

| 想做什么 | 怎么做 |
| --- | --- |
| 连续录入多人 | 第 1 步点「逐个录入人员」或人员库的「+ 新增人员」，填完点**「保存并继续添加」**，表单清空但前一位已经存好 |
| 改某个人的归属 | 人员库点「编辑」，身份组是**下拉单选**、项目组是**复选框可多选**；或者在第 2 步的表格里直接用「身份组」下拉改，改完自动归到新组下面 |
| 新建分组 | 填名字 → 选类型（身份组 / 项目组）→「添加分组」。默认已有**研究生 / 本科生 / AI 补充**三个身份组 |
| 按分组发放 | 第 2 步顶部点分组名＝整组全选/全不选；或人员库里按组筛选后「将当前列表加入本次」 |
| 给某一组统一设金额 | 第 2 步表格里的**分组表头行**点「给本组设金额…」，只改这一组 |
| 搜索 | 人员库上方搜索框，按姓名或学号过滤 |
| 删除分组 | 选中分组后「删除/改名」。**组里的人会保留**（身份组删掉后变成"未分组"） |
| 备份 / 迁移 | 「备份人员库」导出一份 JSON；换电脑后用「导入备份」还原（按分组名合并） |
| 把某人移出本次 | 第 2 步行尾的 `×`，或「将未勾选人员移出本次」——**只移出本次，档案还在人员库** |
| 清空本次名单 | 第 1 步「清空本次名单（保留人员库）」 |

> 人员库存在 `app/people.sqlite3`，本次工作台状态也存在同一个库里。
> 想彻底重来又不想丢人：用「清空本次名单」；想连人员一起清掉，才去人员库里逐个删除。

## 三步走

页面顶上是一条三步走，每步下面实时显示状态（`已导入 12 人` / `已勾选 10 / 12 人` / `10 人 · 合计 12,000 元`）。
点步骤条可以来回切换，**关掉浏览器再打开会回到上次那一步**。

也可以用网址直接跳转（可收藏）：

| 网址 | 效果 |
| --- | --- |
| `#step=1` / `#step=3` | 直接打开某一步 |
| `#drawer=1` | 打开时展开「发放信息」抽屉 |
| `#step=2&batch=1` | 打开第 2 步并展开「批量填入一列」 |

### 第 1 步 · 定项目类型、兼职时段、导入名单

**先选「项目类型」**——`科研经费` 或 `非科研经费`。这一步决定导出时套哪份 Word 底板：

| 项目类型 | 底板 | 明细表多出来的列 |
| --- | --- | --- |
| 科研经费 | `武汉大学学生劳务费发放明细表（科研经费）.docx` | **发放事由及依据** |
| 非科研经费 | `武汉大学学生劳务费发放明细表（非科研经费）.docx` | **所在学院 / 标准 / 工时** |

选错类型也没关系，导出的列会跟着变；换类型不需要重新录入人员。

**再点一下「兼职时段」**——顶部一排月份按钮，点一下即选定（选中的高亮打勾），也可以自己填。
它决定了 Word 表头的「兼职时段」和导出文件名开头的月份。
点「改预设…」维护那一排月份（默认是 **2026年6月 起往后 6 个月**）。

**导入时先选「导入到分组」**（关键）：

```
导入到分组  [ 研究生 ▾ ]      ← 这份名单整批归入「研究生」
```

| 选什么 | 结果 |
| --- | --- |
| 某个身份组（如「研究生」） | **整份名单一次性导入该组**，一次事务写入；列表里已有其他身份组的人会**先拦下来提示**，不会重复发放 |
| `不改变分组（按学号匹配）` | 只按学号匹配已有的人；没匹配到的进人员库但不分组 |

三个导入按钮：

- **选择文件** —— `.xls` / `.xlsx` / `.csv`，也支持拖拽
- **粘贴名单** —— 从 Excel 复制后贴进来，逗号 / 制表符 / 空格分隔都行
- **逐个录入人员** —— 存进长期人员库，可连续录入、随时修改

导入预览里会多一列「分组」，一眼看出每个人会落到哪个组、有没有冲突。
导入的人会**自动并入人员库**（按学号匹配），所以下次不用再导一遍。

**有哪列就收哪列**，列名和顺序都自动识别：

| 列名（认这些写法） | 收进哪里 |
| --- | --- |
| 学号、学生学号、工号、编号 | 学号 |
| 姓名、学生姓名、名字 | 姓名 |
| 学院、所在学院、院系、单位 | 所在学院 |
| 标准、单价 | 标准（元/时） |
| 工时、时长、小时 | 工时 |
| 助研津贴、津贴、补贴、金额、实发 | 实发金额 |
| 勾选、选中、是否发放、本次发放 | 要不要发（写「是」才算） |

- 原来的 `助研费用发放模版.xls`（只有学号/姓名/津贴三列）照样能导
- **粘贴时不带表头也能认**：按列数 + 值的内容判断（第 3 列是「计算机学院」就当学院，是纯数字就当金额）。
  但**带上表头绝不会猜错**，建议连表头一起选
- 导入后弹预览，标出哪些是**新增**、哪些是**更新已有**（按学号或姓名匹配，不会重复）

### 第 2 步 · 勾选学生、设置补贴费与工时

**左边打勾 = 这次要发谁。**

顶部一排补贴费按钮，点一下就设好：

```
补贴费   500   800   1000   1200   1500   1600   2000   [按标准×工时]   [批量填入一列…]  [改预设…]
```

- **点按钮** → 已勾选的学生全部设为该金额（输入框变**蓝底**，表示手填优先）
- **先点进某一行的金额格再点按钮** → 只改那一行
- **按标准×工时** → 撤销手填，改回自动计算
- **改预设…** → 逗号或换行分隔随便改，支持小数，改完自动保存

表格三列的含义：

| 列 | 说明 |
| --- | --- |
| 身份组 | 这个人归哪一组发放。**下拉直接改**，改完自动归到新组下面 |
| 标准（元/时） | 单价 |
| 工　时 | 手动填 |
| 实发金额 | 默认自动 = 标准 × 工时；手填后变蓝底，以你填的为准 |

三个数字列整列有淡蓝底并右对齐，一眼能看出"这几列是要填的"。

**按分组勾选（推荐用法）**：表格会**按身份组分段**，每段前面有一行分组表头：

```
☑ 研究生   2 人 · 已勾选 0 人   [全选本组] [全不选本组] [给本组设金额…]
   ☐ 张三   20260001   ...
   ☐ 李四   20260002   ...
☑ 本科生   1 人 · 已勾选 1 人   [全选本组] [全不选本组] [给本组设金额…]
   ☑ 王五   20260003   ...
```

- 表格**上方**还有一排分组按钮（`研究生 0/2`、`本科生 1/1`），**点一下＝整组全选或全不选**
- 加好勾之后，点这一排的分组名再点顶部的金额按钮，就是「这一组统一多少钱」
- 或者直接用分组表头行的 **「给本组设金额…」**，输入金额只改这一组
- 所以一次发放可以这样做：勾「研究生」→ 设 1200；勾「本科生」→ 设 800，各发各的

**「所在学院」的兜底规则**（顺序）：

1. 名单里写了 → 用名单里的
2. 名单里空着 → 用「发放信息」抽屉里的默认学院
3. 都没有 → 国家网络安全学院

自动补的学院显示成**灰色斜体**，鼠标停上去有说明；你手动改一下它就变成正常黑色。
⚠️ 如果名单文件**根本没有「所在学院」这一列**，那所有人都会用默认学院——这时候改抽屉里的默认值，或在文件里补上这一列。

### 第 3 步 · 导出

顶部先给一份回顾（将导出多少人、总工时、合计金额，有没有人漏填姓名），下面是四个导出按钮：

| 按钮 | 产物 | 用途 |
| --- | --- | --- |
| Word 明细表 | `武汉大学学生劳务费发放明细表`，格式与模板一致，含合计行。**只含已勾选的学生，并按学号从小到大排序** | 存档、打印 |
| PDF 明细表 | 与上面那份 Word **同一个底板、同样内容**，直接出 PDF，不需要装 Office | **按项目类型提交的劳务费明细 PDF** |
| 系统上传 Excel | **只有 3 列**：学号 / 姓名 / 助研津贴(三兼费)，只含已勾选的人 | 上传到学校系统（要求每人有学号） |
| 名单 Excel | **7 列**：勾选 / 学号 / 姓名 / 所在学院 / 标准 / 工时 / 助研津贴。**已勾选的写「是」，未勾选的也保留**（勾选列留空），并按学号升序 | 人员备选池，下次直接导回来 |
| 全部导出 | 一次导出上面四份 | 一次搞定 |

> 名单里保留"未勾选的人"是故意的：这份文件本身就是你的**人员备选池**。
> 下次做新一期时把它拖回来导入，勾选状态会原样恢复，改几个勾就能直接用。
> （不过现在人员已经长期存在人员库里了，这份 Excel 更多是给别人看或留档。）

文件会**自动下载**，同时保存到 `output/` 文件夹，页面上也能点「重新下载」。

PDF 是程序自己排版的（不依赖 Word / LibreOffice），中文字体用系统宋体；
如果 PDF 里中文变成方块，用环境变量指定字体：
`BAOXIAO_PDF_FONT="C:/Windows/Fonts/simsun.ttc"`。

## 快速录入

**方式一：批量填入一列（推荐）**

点第 2 步的 **「批量填入一列…」**，选好填「工时 / 标准 / 实发金额」，把从 Excel 复制的一列数字贴进去：

```
已勾选 4 人  本次填入 3 个工时  填入部分小计 3,500 元  另有 1 人未填、保持原样  填完后全表合计 4,300 元
#   学生      工时           实发金额
1   XX      8              800
2   YY    9              900
3   丙        12             1,800
4   丁        — 保持原样 —    800
```

- 按顺序填给**已勾选**的学生，未勾选的自动跳过
- 预览里的金额是**后端按和导出完全相同的口径算的**，所以你看到的数就等于文件里的数
- 选「实发金额」时还能勾 **「填总额，平均分给勾选的人」**
- 值比勾选人数多会直接报错，不会默默填错

**方式二：在表格里直接粘**

在 Excel 里选中要复制的区域 → 回到表格**点一下要开始填的格子** → `Ctrl+V`：

| 你复制的 | 粘贴结果 |
| --- | --- |
| **一列** | 从光标所在格**往下铺**，不动其它列 |
| **多列** | 从光标所在**列开始向右铺**，和 Excel 一样 |
| **单个值** | 不拦截，按浏览器原生行为填进当前格 |
| 未勾选的行 | 自动跳过，并在提示里说明跳了几行 |

数值列里遇到非数字会跳过该格，但同一行其它列照常填，不会整块失败。

**其它省事的操作**

| 想做什么 | 怎么做 |
| --- | --- |
| 一格格敲 | 格子里按 `Enter` 或 `↑` `↓` 跳到上/下一行同一列；`←` `→` 同一行左右移动 |
| 给一批人同一个金额 | 先勾选，再点顶部那排补贴费按钮 |
| 只改一个人 | 点进那一行的金额格，再点金额按钮 |
| 恢复自动计算 | 点「按标准×工时」 |
| 看被截断的长名字 | 鼠标停在输入框上，`title` 提示里有完整内容 |

## 模板与发放信息

表头那些不常改的东西都在右上角 **「发放信息」抽屉**里。抽屉内容：

| 项目 | 说明 |
| --- | --- |
| 明细表表头 | 发放单位 / 财务项目编号 / 兼职时段 / 项目名称 |
| 发放事项说明 | 支持占位符，见下 |
| 名单里没填时的默认值 | 标准、工时、学院 |
| 模板 | 把整套配置存下来复用（含补贴费预设、月份预设） |
| 导入其它 Word 明细表作底板 | 换一份 `.docx` 当基底，**字体格式完全照搬新底板** |

**默认值都是"活"的，不会过期成写死的旧数据：**

| 字段 | 默认怎么来 |
| --- | --- |
| 兼职时段 | **2026年6月**（由 `store.py` 的 `DEFAULT_PERIOD_START` 决定） |
| 月份快捷预设 | **2026年6月 起往后 6 个月**（6/7/8/9/10/11 月） |
| 学院 | 国家网络安全学院（`store.py` 的 `DEFAULT_COLLEGE`） |
| 发放事项说明 | 占位符版本，自动跟着名单和时段走 |

> **想换起始月份**：改 `store.py` 里的一行 `DEFAULT_PERIOD_START = "2026年6月"` 即可，
> 默认时段和那一排月份按钮都会跟着变。日常换月份不用改代码——在第 1 步点一下就行。

模板按钮：**套用模板 / 存为新模板 / 覆盖当前 / 删除模板**，存的时候会问要不要连学生名单一起记住。

### 发放事项说明的占位符

这不影响你自己的数据：留空就用不点名的固定说法，自己写了就原样保留。

| 占位符 | 替换为 |
| --- | --- |
| `{人数}` | 勾选的学生人数 |
| `{第一位学生}` | 第一位学生的姓名 |
| `{时段}` | 兼职时段 |
| `{项目名称}` | 项目名称 |

留空则自动生成：`本人项目组本科生、研究生在{时段}参与科研项目{项目名称}的研究。负责相关研发工作。各人的参与项目和具体工作见下表。`

> 说明段落**不再写「XXX 等 N 位」**——那种写法一旦改名单就过期了。
> 谁参与了什么项目、做了什么工作，写在下面每个人的「发放事由及依据」里。

### 每行的「发放事由及依据」（科研表）

科研表的最后一列按模板生成，**不写"xxx等"**：

```
研究生张三参与了【待填写项目名称】项目，完成了【待填写工作内容】工作。
```

规则（都在「发放信息」抽屉最下面的那一段里改）：

| 占位符 | 换成 |
| --- | --- |
| `{身份}` | 这个人的身份组名（研究生 / 本科生 / AI 补充） |
| `{姓名}` / `{学号}` / `{时段}` | 对应内容 |

**`【】` 括起来的是"待填写"**：导出时会去掉方括号，在 Word / PDF 里显示成**黄色高亮**，
提醒你补写；在抽屉里填了值就直接写值、不再高亮。

| 抽屉里的设置 | 效果 |
| --- | --- |
| 工作内容 | 填了就写进每个人的事由（例如"数据清洗与模型训练"） |
| 事由用哪个项目组 | 选一个项目组 → **这一组的人事由里统一写这个项目名**；不选就留成高亮，等你补 |
| 事由模板 | 想换句式就改这里；抽屉底部有实时预览（高亮效果和导出文件一致） |

- **某个人自己填了事由**（第 2 步表格里的「发放事由及依据」列）→ 以他自己写的为准，不用模板
- 项目名只在**你选了项目组**时才自动填；不选不会拿表头的"项目名称"去顶，
  因为表头那个是整张表的项目，不一定等于某个人实际参与的项目

### 页面上的数字

页面、Word、PDF、Excel **完全同一个口径**：

- 金额按「分」四舍五入（`RoundHalfUp`），所以 `100.5 × 3` 是 **301.5**，不会出现 `301.49999999999994`
- 合计按整数"分"累加，明细加起来一定等于合计
- 表格里的金额带千分位（`1,200`、`2,000`），和页面上看到的一致

### 文件名是怎么拼的

```
「兼职时段」 _ 「文件名备注」 _ 日期 _ 劳务费发放明细表.docx
   2026年9月      9月第一批       20260918
```

**换月份只改「兼职时段」这一个字段**。如果文件名里出现两个月份（比如 `2026年6月_9月第一批`），
那是兼职时段还停在 6 月、而备注里填了 9 月——把时段改掉即可。

## 导出格式为什么和模板一模一样

程序不是"重新画"一张表，而是**复制你的模板文件**，只在 XML 层面把文字填进去，
并且**字体一律从模板对应的单元格里取**，包括：

- 表头字段（Times New Roman + 宋体）
- 学号 / 学院列的 8 磅字号（`w:sz=16`）
- 项目名称里"数字用 Times New Roman、中文用宋体"的混排
- 说明段落的等线 10 磅

所以字体、字号、单元格合并、边框、行高全部原样保留。
想换格式就换底板：**导入其它 Word 明细表作底板**，之后导出就跟着新底板走。

## 常见问题

**Windows 双击 run.cmd 提示找不到 Python？**
装 Python 3.8+（<https://www.python.org/downloads/>），安装时**务必勾选** *Add python.exe to PATH*。
装了微软商店版 Python 也没关系，`run.cmd` 会优先挑选**已经装好依赖**的那个解释器。

**macOS / Linux 提示 Permission denied？**
```bash
chmod +x run.sh
```

**依赖装不上？**
`run.py` 会自动装到 `vendor/pylib2`（`vendor/pylib` 坏了就绕开它）。手动装：
```bash
python3 -m pip install --target vendor/pylib2 python-docx xlrd xlwt openpyxl reportlab
```
依赖目录也可以放到别处（例如没有写权限时）：
```bash
BAOXIAO_VENDOR_DIR=/path/to/pylib python3 run.py
```

**导出 Excel 报 `module 'xlwt' has no attribute 'Workbook'`？**
这是依赖目录被"挡住"了——`vendor/pylib` 里如果留下一个**空的、或读不了**的 `xlwt` 目录
（pip 装到一半失败、权限被改坏时会这样），Python 会把它当成包，于是"能 import 但里面是空的"。

从这一版起程序**自己会处理**：启动时检查每个依赖是否真的能用，
把坏目录排到最后，缺的自动装到 `vendor/pylib2`。**重启一次服务即可**，不用手动删东西。

想彻底清掉那个坏目录（可选，需要管理员权限）：
```powershell
Remove-Item -Recurse -Force vendor\pylib\xlwt, vendor\pylib\xlrd, vendor\pylib\bin
```

**数据会丢吗？**
不会。人员库和本次名单每次修改都会自动写进本机数据库；第 1 步还有「清空本次名单（保留人员库）」。
删掉 `app/people.sqlite3` 才会真正从零开始（建议先用「备份人员库」留一份）。

**换了电脑 / 重装系统，人还在吗？**
在。把整个文件夹拷过去即可；或者在新电脑用人员库的「导入备份」还原一份 JSON 备份。

**导入名单时提示"学号已属于另一位人员"？**
同一个学号只能对应一个人。如果想改名字，请到人员库里「编辑」那一位；
如果确实换了人，先删掉旧的那条再导。

**端口被占用？**
会自动往后找。也可指定：`python3 run.py --port 9000`。

**想让"学院"默认是别的？**
改 `store.py` 里的 `DEFAULT_COLLEGE`，或者在「发放信息」抽屉里改默认学院。

## 开发说明

- 后端只用 Python 标准库做 HTTP 服务；Word 用 `python-docx` 操作 OOXML，
  Excel 用 `xlwt` 写真正的 BIFF8/OLE 格式（后缀 `.xls`），
  PDF 用 `reportlab` 自己排版（读生成的 docx，不是调用 Word）
- 人员库用 SQLite（`people_store.py`）：人员、分组、本次名单在**同一个事务**里提交，
  并带 `revision` 乐观锁——两个页面同时改，后保存的那个会收到中文冲突提示而不是静默覆盖
- 人员删除是**软删除**：能从"未勾选"里移除而不影响档案，且旧页面的过期保存无法把已删的人复活
- 前端是原生 HTML/CSS/JS，没有构建步骤、没有依赖
- 生成的文档通过 OOXML 子元素顺序校验（`w:pPr` / `w:tcPr` 符合 schema 顺序），
  不会触发 Word 的"文档已损坏"提示
- 启动脚本设置 `PYTHONUTF8=1`，中文文件名（如 `助研费用发放列表.xls`）在三个平台上都不会出错

### 跑测试


覆盖：人员库迁移与连续录入、清空本次不删人、自定义分组与多组归属、删除后过期保存被拒、

### 四个容易踩的坑（改代码时注意）

1. **`[hidden]` 必须能压住 `display:flex`。**
   样式表开头有一条全局 `[hidden] { display: none !important; }`。
   少了它，给容器设了 `display:flex/grid` 就会盖掉浏览器默认的 `[hidden]` 规则，
   出现"该隐藏的抽屉一直开着挡住半边屏幕"。**不要删这条。**

2. **`docx_gen.py` 里刻意不定义任何字体常量。**
   字体一律从模板对应的单元格/段落里取（`_split_by_script`），
   所以模板改字体导出就跟着改。加字体常量会让这条链断掉。

3. **改完 Python 代码要重启服务**（关掉 `run.cmd` 窗口再开）。
   Python 进程会把模块缓存在内存里，不重启的话改的代码不生效——
   而且旧进程还会把工作台状态写回数据库，让人以为改动没起作用。

4. **临时目录别用 `tempfile.mkdtemp()` 的默认位置。**
   它创建的目录带 0o700 私有 ACL，在受限账户下反而写不进去（导出会报 PermissionError）。
   `server.py` 的 `staging_dir()` 把暂存目录放在 `output/` 下，就是为了避开这一点。

### 重新提取默认值

换了 `助研费用发放模版.xls` / `助研费用发放说明(1).docx` 之后：

```bash
python extract_defaults.py
```

它会重写 `templates/defaults.json`。注意脚本会把模板里写死的说明文字
换成占位符版本、并把 `period` 留空（表示"用当前月份"）。
