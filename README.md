# 学生劳务费发放助手

本机小工具：**导入名单 → 勾选并设置补贴费/工时 → 按模板导出 Word 明细表和 Excel 名单**。

Windows / macOS / Linux 都能用，只用 Python，不需要 Node、不需要编译、不需要联网。

## 启动

| 平台 | 怎么做 |
| --- | --- |
| Windows | 双击 **`run.cmd`** |
| macOS / Linux | `chmod +x run.sh && ./run.sh` |
| 任意平台 | `python3 run.py` |

浏览器会自动打开 <http://127.0.0.1:8765>。**用完关掉那个终端窗口就停止服务。**

```bash
python3 run.py --port 9000   # 指定端口（默认 8765，被占用会自动往后找）
python3 run.py --no-open     # 不自动开浏览器
```

首次打开会看到两个示例学生（来自你的模板文件），可以直接改成你自己的名单。

## 三步走

页面顶上是一条三步走，每步下面实时显示状态（`已导入 12 人` / `已勾选 10 / 12 人` / `10 人 · 合计 12,000 元`）。
点步骤条可以来回切换，**关掉浏览器再打开会回到上次那一步**。

也可以用网址直接跳转（可收藏）：

| 网址 | 效果 |
| --- | --- |
| `#step=1` / `#step=3` | 直接打开某一步 |
| `#drawer=1` | 打开时展开「发放信息」抽屉 |
| `#step=2&batch=1` | 打开第 2 步并展开「批量填入一列」 |

### 第 1 步 · 定兼职时段、导入名单

**先点一下「兼职时段」**——顶部一排月份按钮，点一下即选定（选中的高亮打勾），也可以自己填。
它决定了 Word 表头的「兼职时段」和导出文件名开头的月份。
点「改预设…」维护那一排月份（默认是 **2026年6月 起往后 6 个月**）。

三个导入按钮：

- **选择文件** —— `.xls` / `.xlsx` / `.csv`，也支持拖拽
- **粘贴名单** —— 从 Excel 复制后贴进来，逗号 / 制表符 / 空格分隔都行
- **手动添加** —— 只加一两个人时用

**有哪列就收哪列**，列名和顺序都自动识别：

| 列名（认这些写法） | 收进哪里 |
| --- | --- |
| 学号、学生学号、工号、编号 | 学号 |
| 姓名、学生姓名、名字 | 姓名 |
| 学院、所在学院、院系、单位 | 所在学院 |
| 标准、单价 | 标准（元/时） |
| 工时、时长、小时 | 工时 |
| 助研津贴、津贴、补贴、金额、实发 | 实发金额 |
| 勾选、选中、是否发放、本次发放 | 要不要发（写「是」才算） |

- 原来的 `助研费用发放模版.xls`（只有学号/姓名/津贴三列）照样能导
- **粘贴时不带表头也能认**：按列数 + 值的内容判断（第 3 列是「计算机学院」就当学院，是纯数字就当金额）。
  但**带上表头绝不会猜错**，建议连表头一起选
- 导入后弹预览，标出哪些是**新增**、哪些是**更新已有**（按学号或姓名匹配，不会重复）

### 第 2 步 · 勾选学生、设置补贴费与工时

**左边打勾 = 这次要发谁。**

顶部一排补贴费按钮，点一下就设好：

```
补贴费   500   800   1000   1200   1500   1600   2000   [按标准×工时]   [批量填入一列…]  [改预设…]
```

- **点按钮** → 已勾选的学生全部设为该金额（输入框变**蓝底**，表示手填优先）
- **先点进某一行的金额格再点按钮** → 只改那一行
- **按标准×工时** → 撤销手填，改回自动计算
- **改预设…** → 逗号或换行分隔随便改，支持小数，改完自动保存

表格三列的含义：

| 列 | 说明 |
| --- | --- |
| 标准（元/时） | 单价 |
| 工　时 | 手动填 |
| 实发金额 | 默认自动 = 标准 × 工时；手填后变蓝底，以你填的为准 |

三个数字列整列有淡蓝底并右对齐，一眼能看出"这几列是要填的"。

**「所在学院」的兜底规则**（顺序）：

1. 名单里写了 → 用名单里的
2. 名单里空着 → 用「发放信息」抽屉里的默认学院
3. 都没有 → 国家网络安全学院

自动补的学院显示成**灰色斜体**，鼠标停上去有说明；你手动改一下它就变成正常黑色。
⚠️ 如果名单文件**根本没有「所在学院」这一列**，那所有人都会用默认学院——这时候改抽屉里的默认值，或在文件里补上这一列。

### 第 3 步 · 导出

顶部先给一份回顾（将导出多少人、总工时、合计金额，有没有人漏填姓名），下面是三个导出按钮：

| 按钮 | 产物 |
| --- | --- |
| Word 明细表 | `武汉大学学生劳务费发放明细表`，格式与模板一致，含合计行。**只含已勾选的学生，并按学号从小到大排序** |
| Excel 名单 | **7 列**：勾选 / 学号 / 姓名 / 所在学院 / 标准 / 工时 / 助研津贴。**已勾选的写「是」，未勾选的也保留**（勾选列留空），并按学号升序 |
| 两个都要 | 一次导出上面两份 |

> 名单里保留"未勾选的人"是故意的：这份文件本身就是你的**人员备选池**。
> 下次做新一期时把它拖回来导入，勾选状态会原样恢复，改几个勾就能直接用。

文件会**自动下载**，同时保存到 `output/` 文件夹，页面上也能点「重新下载」。

## 快速录入

**方式一：批量填入一列（推荐）**

点第 2 步的 **「批量填入一列…」**，选好填「工时 / 标准 / 实发金额」，把从 Excel 复制的一列数字贴进去：

```
已勾选 4 人  本次填入 3 个工时  填入部分小计 3,500 元  另有 1 人未填、保持原样  填完后全表合计 4,300 元
#   学生      工时           实发金额
1   XX      8              800
2   YY    9              900
3   丙        12             1,800
4   丁        — 保持原样 —    800
```

- 按顺序填给**已勾选**的学生，未勾选的自动跳过
- 预览里的金额是**后端按和导出完全相同的口径算的**，所以你看到的数就等于文件里的数
- 选「实发金额」时还能勾 **「填总额，平均分给勾选的人」**
- 值比勾选人数多会直接报错，不会默默填错

**方式二：在表格里直接粘**

在 Excel 里选中要复制的区域 → 回到表格**点一下要开始填的格子** → `Ctrl+V`：

| 你复制的 | 粘贴结果 |
| --- | --- |
| **一列** | 从光标所在格**往下铺**，不动其它列 |
| **多列** | 从光标所在**列开始向右铺**，和 Excel 一样 |
| **单个值** | 不拦截，按浏览器原生行为填进当前格 |
| 未勾选的行 | 自动跳过，并在提示里说明跳了几行 |

数值列里遇到非数字会跳过该格，但同一行其它列照常填，不会整块失败。

**其它省事的操作**

| 想做什么 | 怎么做 |
| --- | --- |
| 一格格敲 | 格子里按 `Enter` 或 `↑` `↓` 跳到上/下一行同一列；`←` `→` 同一行左右移动 |
| 给一批人同一个金额 | 先勾选，再点顶部那排补贴费按钮 |
| 只改一个人 | 点进那一行的金额格，再点金额按钮 |
| 恢复自动计算 | 点「按标准×工时」 |
| 看被截断的长名字 | 鼠标停在输入框上，`title` 提示里有完整内容 |

## 模板与发放信息

表头那些不常改的东西都在右上角 **「发放信息」抽屉**里。抽屉内容：

| 项目 | 说明 |
| --- | --- |
| 明细表表头 | 发放单位 / 财务项目编号 / 兼职时段 / 项目名称 |
| 发放事项说明 | 支持占位符，见下 |
| 名单里没填时的默认值 | 标准、工时、学院 |
| 模板 | 把整套配置存下来复用（含补贴费预设、月份预设） |
| 导入其它 Word 明细表作底板 | 换一份 `.docx` 当基底，**字体格式完全照搬新底板** |

**默认值都是"活"的，不会过期成写死的旧数据：**

| 字段 | 默认怎么来 |
| --- | --- |
| 兼职时段 | **2026年6月**（由 `store.py` 的 `DEFAULT_PERIOD_START` 决定） |
| 月份快捷预设 | **2026年6月 起往后 6 个月**（6/7/8/9/10/11 月） |
| 学院 | 国家网络安全学院（`store.py` 的 `DEFAULT_COLLEGE`） |
| 发放事项说明 | 占位符版本，自动跟着名单和时段走 |

> **想换起始月份**：改 `store.py` 里的一行 `DEFAULT_PERIOD_START = "2026年6月"` 即可，
> 默认时段和那一排月份按钮都会跟着变。日常换月份不用改代码——在第 1 步点一下就行。

模板按钮：**套用模板 / 存为新模板 / 覆盖当前 / 删除模板**，存的时候会问要不要连学生名单一起记住。

### 发放事项说明的占位符

| 占位符 | 替换为 |
| --- | --- |
| `{人数}` | 勾选的学生人数 |
| `{第一位学生}` | 第一位学生的姓名 |
| `{时段}` | 兼职时段 |
| `{项目名称}` | 项目名称 |

留空则自动生成：`本人项目组XXX等N位本科生、研究生在{时段}参与科研项目{项目名称}的研究。负责相关研发工作。明细见下表：`

> ⚠️ 如果你在说明里**直接写死**「2026年6月」「等9位」这种具体数字，改时段或改名单时它**不会**跟着变，
> 导出的文档就会和文件名对不上。要么用占位符，要么留空让程序生成。

### 文件名是怎么拼的

```
「兼职时段」 _ 「文件名备注」 _ 日期 _ 劳务费发放明细表.docx
   2026年9月      9月第一批       20260918
```

**换月份只改「兼职时段」这一个字段**。如果文件名里出现两个月份（比如 `2026年6月_9月第一批`），
那是兼职时段还停在 6 月、而备注里填了 9 月——把时段改掉即可。

## 导出格式为什么和模板一模一样

程序不是"重新画"一张表，而是**复制你的模板文件**，只在 XML 层面把文字填进去，
并且**字体一律从模板对应的单元格里取**，包括：

- 表头字段（Times New Roman + 宋体）
- 学号 / 学院列的 8 磅字号（`w:sz=16`）
- 项目名称里"数字用 Times New Roman、中文用宋体"的混排
- 说明段落的等线 10 磅

所以字体、字号、单元格合并、边框、行高全部原样保留。
想换格式就换底板：**导入其它 Word 明细表作底板**，之后导出就跟着新底板走。

## 文件结构

```
auto_baoxiao/
├─ run.cmd                     Windows 双击入口
├─ run.sh                      macOS / Linux 入口
├─ run.py                      通用入口（找依赖 + 起服务 + 开浏览器）
├─ server.py                   本地 HTTP 服务（界面 + 文件生成接口）
├─ docx_gen.py                 Word 明细表生成（OOXML 层面填充，字体照搬模板）
├─ xls_gen.py                  Excel 名单读写 + 名单列识别
├─ store.py                    配置/模板存储、默认值
├─ extract_defaults.py         从模板文件重新提取默认值（换了模板可重跑）
├─ 助研费用发放模版(1).xls        你的原始名单模板
├─ 助研费用发放说明(1).docx      你的原始明细表模板
├─ web/                        前端（原生 HTML/CSS/JS，无构建步骤）
│  ├─ index.html
│  ├─ style.css
│  └─ app.js
├─ templates/
│  └─ defaults.json            内置默认值（由 extract_defaults.py 生成）
├─ app/
│  └─ settings.json            当前工作台状态（自动保存；删掉即恢复初始）
├─ output/                     导出的文件
└─ vendor/pylib/               依赖（xlwt，随目录一起拷贝）
```

**数据都存在普通文件里**：工作台状态在 `app/settings.json`，模板在 `templates/`，
导出的文件在 `output/`。整个文件夹拷到别的电脑就能继续用。

## 常见问题

**Windows 双击 run.cmd 提示找不到 Python？**
装 Python 3.8+（<https://www.python.org/downloads/>），安装时**务必勾选** *Add python.exe to PATH*。
装了微软商店版 Python 也没关系，`run.cmd` 会优先挑选**已经装好依赖**的那个解释器。

**macOS / Linux 提示 Permission denied？**
```bash
chmod +x run.sh
```

**依赖装不上？**
`run.py` 会自动装到 `vendor/pylib`。手动装：
```bash
python3 -m pip install --target vendor/pylib python-docx xlrd xlwt openpyxl
```

**数据会丢吗？**
不会。每一处修改都会自动写进 `app/settings.json`；第 1 步还有「清空重来」。

**端口被占用？**
会自动往后找。也可指定：`python3 run.py --port 9000`。

**想让"学院"默认是别的？**
改 `store.py` 里的 `DEFAULT_COLLEGE`，或者在「发放信息」抽屉里改默认学院。

## 开发说明

- 后端只用 Python 标准库做 HTTP 服务；Word 用 `python-docx` 操作 OOXML，
  Excel 用 `xlwt` 写真正的 BIFF8/OLE 格式（后缀 `.xls`）
- 前端是原生 HTML/CSS/JS，没有构建步骤、没有依赖
- 生成的文档通过 OOXML 子元素顺序校验（`w:pPr` / `w:tcPr` 符合 schema 顺序），
  不会触发 Word 的"文档已损坏"提示
- 启动脚本设置 `PYTHONUTF8=1`，中文文件名（如 `助研费用发放模版(1).xls`）在三个平台上都不会出错

### 两个容易踩的坑（改代码时注意）

1. **`[hidden]` 必须能压住 `display:flex`。**
   样式表开头有一条全局 `[hidden] { display: none !important; }`。
   少了它，给容器设了 `display:flex/grid` 就会盖掉浏览器默认的 `[hidden]` 规则，
   出现"该隐藏的抽屉一直开着挡住半边屏幕"。**不要删这条。**

2. **`docx_gen.py` 里刻意不定义任何字体常量。**
   字体一律从模板对应的单元格/段落里取（`_split_by_script`），
   所以模板改字体导出就跟着改。加字体常量会让这条链断掉。

3. **改完 Python 代码要重启服务**（关掉 `run.cmd` 窗口再开）。
   Python 进程会把模块缓存在内存里，不重启的话改的代码不生效——
   而且旧进程还会把工作台状态写回 `app/settings.json`，让人以为改动没起作用。

### 重新提取默认值

换了 `助研费用发放模版.xls` / `助研费用发放说明(1).docx` 之后：

```bash
python extract_defaults.py
```

它会重写 `templates/defaults.json`。注意脚本会把模板里写死的说明文字
换成占位符版本、并把 `period` 留空（表示"用当前月份"）。
